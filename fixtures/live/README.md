# Static live-review fixtures

These committed, side-effect-free text files are intended for a transparent
Studionet reviewer lifecycle after the intended deployment account is confirmed.
Each directory can be used as a member endpoint base through GitHub raw content,
with `/probe-1.txt`, `/probe-2.txt`, and `/probe-3.txt` as the shared probe paths.

The `diverse-a`, `diverse-b`, and `diverse-c` profiles are pairwise different on
two of three decisive propositions. `clone-a` intentionally duplicates
`diverse-a`. `inconclusive` contains non-answers intended to classify as
`UNCLEAR`; the consensus result remains authoritative.

These files are fixtures, not an application backend. Their committed content
and eventual raw URLs are publicly auditable.
